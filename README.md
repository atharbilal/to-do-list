# a.java - Java To-Do List Tracker (CLI)

This is a simple command-line To-Do List Tracker written in Java. It allows you to:

- Add tasks (with recommended suggestions or your own)
- List all tasks
- Mark tasks as done (with a user-friendly selection)
- Get motivational quotes
- Personalized greeting and goal tracking

## How to Run

1. Make sure you have Java (JDK 17 or later) installed.
2. Open a terminal in this directory.
3. Compile:
   ```sh
   javac a.java
   ```
4. Run:
   ```sh
   java a
   ```

## Features
- Friendly greeting and user info prompt
- Recommended and custom tasks
- Motivational quotes
- Easy marking of completed tasks
